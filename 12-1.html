CSS 变量

使用自定义属性（Custom Properties）统一管理颜色、尺寸等值，实现一处修改、全局生效。

赵壁文
01

定义变量

在 :root 中声明

CSS 变量以 -- 开头，通过 var() 引用。以下卡片展示本页面使用的部分变量。

颜色变量

用于文字、背景、边框等。

--zhao_ink: #0b2545; --zhao_blue: #1d5fad; --zhao_accent: #e8a33d;

尺寸变量

圆角、间距、阴影。

--zhao_radius: 14px; --zhao_gap: 24px; --zhao_shadow: 0 10px 30px ...;

局部覆盖

局部变量可覆盖全局变量。

.zhao_stage { --zhao_local: #e8a33d; }
