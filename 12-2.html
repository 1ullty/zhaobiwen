LESSON 12-2

Grid 布局

使用 grid-template-areas 命名区域，直观地描述二维页面结构。

01

区域划分

3 列 × 4 行

每个区域由字母命名，跨行跨列的区域自动合并，最终形成如下布局：

a1 行 1 列
b1-2 行 · 2-3 列
c2-4 行 · 1 列
d3-4 行 · 2 列
e3 行 3 列
f4 行 3 列
02

核心代码

grid-template-areas
.zhao_grid { display: grid; grid-template-columns: repeat(3, 1fr); grid-template-areas: "a b b" "c b b" "c d e" "c d f"; } .zhao_a { grid-area: a; } .zhao_b { grid-area: b; } .zhao_c { grid-area: c; } .zhao_d { grid-area: d; } .zhao_e { grid-area: e; } .zhao_f { grid-area: f; }
