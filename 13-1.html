列表图标（fa-ul）

  • 支持 woff2 字体格式，加载速度快
  • 图标即字体，可用 CSS 自由控制颜色和大小
  • 支持旋转、动画、堆叠等高级用法
  • 提供 solid / regular / brands 三种风格
  • 超过 2000 个免费图标可供选择

技术原理

@font-face {
  font-family: "Font Awesome 6 Free";
  src: url("../webfonts/fa-solid-900.woff2");
}

.fa-house::before {
  content: "\f015"; /* Unicode 私有区 */
}
