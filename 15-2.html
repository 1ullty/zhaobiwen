条件结构

if / else if / else · switch · 三元运算符

程序根据条件的真假选择不同的执行路径：if...else if...else 逐条检查、命中即止；switch 按值精确匹配；三元运算符是只有两个分支的简写。

当前分数 var zbw_score = 85;
switch 匹配 switch ( Math.floor( zbw_score / 10 ) )
三元运算符 zbw_score >= 60 ? '及格' : '不及格'

循环结构

for · while · do...while · for...in · for...of · break · continue

循环让一段代码重复执行：for 适合已知次数，while 先判断后执行，do...while 至少执行一次，break 提前终止，continue 跳过本次。点击按钮观看每次迭代的动画。
